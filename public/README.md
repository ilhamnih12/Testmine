# public/

Asset statis situs.

- `engine/` — **hasil `npm run download-engine`** (git-ignored). Berisi
  rilis Luanti WASM (launcher + wasm + packs) yang disajikan same-origin di
  `/engine`. Hapus folder ini untuk kembali ke mode mirror publik.
- `icons/` — ikon PWA.
- `logo.svg` — logo Minetest (© TSamuel, via Wikipedia, dari
  Kaesual/minetest-wasm).
- `assets/screenshot.webp` — tangkapan layar in-game.
- `manifest.json`, `sw.js` — PWA.
